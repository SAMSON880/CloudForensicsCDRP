# Cloud Forensics CDRP — Complete B.Tech Project Reconstruction

This project is a working reconstruction based on the uploaded B.Tech presentation
"Toward a Conflict Resolution Protocol for Cloud Forensics Investigation".

The presentation specifies Java, HTML/CSS and MySQL, and describes Admin, User and
Seller/Provider modules plus a comparison/dispute-resolution protocol.

## What is included

- Java 17 web application
- HTML/CSS UI generated by the Java server
- MySQL/JDBC database support
- Automatic in-memory demo mode when MySQL is not configured
- Admin login, user authorization and dataset administration
- User registration/login, investigation-type search and dataset search
- Seller/provider registration/login, dataset upload and dataset viewing
- Consumer/provider record comparison
- CDRP/CCRP-style dispute resolution result
- Forensic chain filtering
- Analytics pages for investigation, shopping type and shopping mall categories
- Database schema in `database/schema.sql`

## Replit

1. Import this ZIP as a new Replit app.
2. The `.replit` file is already configured to run Maven.
3. Click Run.
4. Open the web preview.

The application works in DEMO mode without a database, so you can test the UI
immediately. To use persistent MySQL storage, configure the environment variables
listed below and run the SQL schema.

## MySQL environment variables

MYSQL_URL=jdbc:mysql://HOST:3306/cloud_forensics
MYSQL_USER=YOUR_USER
MYSQL_PASSWORD=YOUR_PASSWORD

If those variables are missing, the app uses in-memory storage for demonstration.
No real cloud resources or forensic evidence are accessed by this academic demo.

does not contain the original source code, so this implementation follows the
documented modules and algorithmic idea rather than claiming to be the original
private code.
